# Provador virtual de quadros — Maperia

Código do botão "Ver na minha parede" da loja [maperia.com.br](https://www.maperia.com.br): o cliente usa a câmera do celular (ou uma foto da parede) para ver o quadro na própria parede, com as medidas reais do produto.

- Roda só no navegador do visitante. Nenhuma imagem da câmera é gravada ou enviada.
- `provador.js`: código-fonte comentado.
- `provador.min.js`: versão compacta usada pela loja.

Cada versão publicada fica marcada com uma etiqueta (ex.: `v0.3.0`) e é servida pelo jsDelivr:
`https://cdn.jsdelivr.net/gh/<conta>/provador-virtual@v0.3.0/provador.min.js`
